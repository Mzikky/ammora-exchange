# Ammora Swap — minimal exchange on GIWA Sepolia testnet

A minimal token-swap UI built with the public Ammora SDK
(`@ammora-protocol/sdk@0.3.9` + `viem`) for the Ammora builder mission
("Ship an exchange or launchpad with the Ammora SDK").

**Testnet only. No real funds.** Chain: GIWA Sepolia, chain id 91342,
RPC `https://sepolia-rpc.giwa.io`, explorer `https://sepolia-explorer.giwa.io`.

## What it does

- Connects a wallet via `window.ethereum` (viem `WalletClient`); the user
  signs in their own wallet. The app never touches keys, seeds, or key files.
  It auto-switches (or adds) GIWA Sepolia, chain 91342.
- Six markets, all WETH ⇄ launched token on that token's DBC bonding curve
  (model `"dbc"` in the SDK). Every market was verified live on-chain
  2026-11-16 (curve status 1 = active, working buy quote):
  CBRL, YUZU, MIMO, AMM, APAD, AROMMA — see `src/tokens.ts` for addresses.
  All launched tokens use 9 decimals; WETH uses 18.
- Quote via `AmmoraSwapClient.prepareExactIn` (read-only): expected output,
  minimum received at 0.5% slippage, route, quote block, approval requirement.
- Swap via `prepared.execute(wallet)` — the SDK handles the exact approval,
  simulation, swap, and receipt-block output verification, with live status
  updates. Tx hash + explorer links are shown afterwards.
- Wrap box: ETH → WETH. Native ETH input is **not** enabled for these DBC
  pools in this deployment (verified live), so buys pay in WETH (ERC-20).

## Run locally

```bash
cd ~/workspace/ammora-exchange
npm install        # already done on this VM
npm run dev        # dev server (default http://localhost:5173)
npm run build      # type-check + production build -> dist/
npm run preview    # serve the built dist/ (default http://localhost:4173)
```

Deploy by hosting the `dist/` directory as static files (any static host).

- **Buy PASS** — 0.001 WETH → 25,565.83 CBRL, min 25,438.00 (0.5% slippage),

- **Sell PASS** — 1,000 CBRL → 0.000012789 WETH, min 0.000012726.
- **Native ETH input FAILS by design** — "the selected Factory or pool is not
  enabled by the reviewed native execution registry". The app therefore uses
  WETH + the wrap box.
- Graduated AMT pool `0x1F110B9E52277A8BC6da7057f83d9b73a58054Ed` is not
  quotable (`PriceRangeViolation` as concentrated) — not included.
- `tAMM` was **not** found among the 110 launches scanned (blocks
  37,724,988–41,494,988); it was not launched via the V4 factory in that
  window, so no tAMM market is offered.

## User checklist (from their phone)

1. Open the deployed site in a wallet browser (MetaMask / Binance Wallet).
2. Connect — the app adds/switches to GIWA Sepolia (91342) automatically.
3. The wallet `0x7003…eD8c5` already holds ~0.084 GIWA testnet ETH, so no
   faucet trip is needed for gas. (Faucets if ever needed:
   https://faucet.giwa.io — 0.005 ETH/24h;
   https://faucet.lambda256.io/giwa-sepolia — 0.01 ETH/24h.)
4. Wrap a little ETH → WETH (e.g. 0.01), pick a market, Get quote, Swap.
   Two wallet confirmations on first swap per token: one approval, one swap.

## Project files

- `index.html`, `src/main.ts`, `src/ammora.ts`, `src/tokens.ts`,
  `src/style.css` — the app.
- `package.json`, `tsconfig.json`, `vite.config.ts` — build config.
- `dist/` — production build output (generated by `npm run build`).
- `verify-quote.mjs` — live read-only quote verification script.
- `check-curves.mjs` — curve-state + quote checks for candidate launches.
- `discover-launches.mjs`, `launches.log`, `launches-early.log` — on-chain
  LaunchCreated scans (49 + 61 launches) used to pick the markets.
- `dump-catalog.mjs`, `catalog.json` — SDK deployment catalog dump.
- `discover.mjs`, `discover.log` — superseded by the chunked scanner
  (the GIWA RPC caps `eth_getLogs` at 10,000 blocks per call).
